# GenAI Quiz Application

## Description

A Streamlit web application that allows users to test their knowledge of Generative AI.

## Technologies Used

- Python
- Streamlit

## Features

- 10 Multiple Choice Questions
- Interactive UI
- Instant Score
- Percentage Calculation
- Correct Answers Display
- Responsive Design

## Installation

```bash
git clone <repository-url>
cd genai-quiz-app
pip install -r requirements.txt
streamlit run app.py
```
